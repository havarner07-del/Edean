# TI-84 Programs (Precalculus)

## Python programs (TI-84 Plus CE Python, color screen)

| File | Covers | What it does |
|------|--------|--------------|
| `CONICS.py` | 10.1–10.3 | Ellipse/circle, hyperbola, parabola: center, vertices, co-vertices, foci, a/b/c, eccentricity, asymptotes, directrix, latus rectum. Works from standard form, from features (a, b, c, focus, directrix), or from general form `Ax^2+Cy^2+Dx+Ey+F=0` (completes the square for you). |
| `SEQ.py` | 11.1–11.4 | Arithmetic and geometric sequences (from a1 & d/r or from two terms), a_n, S_n, infinite sums, repeating decimal to fraction, terms/sum of any a_n formula, recursive sequences, induction formula checker. |
| `COUNT.py` | 11.5–11.6 | n!, nPr, nCr, binomial expansion, k-th term, term containing x^m, Pascal row, letter arrangements (MISSISSIPPI), fundamental counting, circular arrangements. |
| `ANGLES.py` | 4.1 | Degrees and radians (answers in terms of pi), DMS, coterminal angles, reference angle, quadrant, complement/supplement, arc length, sector area, linear/angular speed. |
| `TRIGFN.py` | 4.2–4.4 | Exact values of all 6 trig functions (unit-circle angles), point (x, y) on the terminal side, one trig value + quadrant to the other five, right-triangle solver. |
| `BINOM.py` | 11.5 | Quick binomial expander (same as COUNT option 4). |

Every program has a **Formulas** option with the things worth memorizing.

Angles can be typed as degrees (`150`) or radians with pi (`5pi/6`), or `2r` for 2 radians.
Values accept fractions like `-3/5`. In TRIGFN option 3 you can also type things like `2sqrt(2)/3`.

**Install:** open TI Connect CE, connect the calculator, and drag the `.py` files onto it.
**Run:** `prgm` → Python App → choose the file → Run.

## TI-BASIC (older black-and-white TI-84 Plus)

`BINOM-TI-BASIC.txt` is a binomial expander to type in by hand.
